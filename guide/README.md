## 如何阅读

1. 先读 **01** 理解 Obsidian 的完整设计蓝图(最成熟、最值得借鉴的标杆)。
2. 再读 **02** 对比开源替代品的不同取舍,尤其是开源代码可以直接阅读学习的项目。
3. **03** 是按技术专题的纵向深挖,做选型决策时查阅。
4. **04** 是最终落地建议,可作为自研项目的起点架构。

## 调研方法说明

本调研基于以下类型资料交叉验证:

- Obsidian 官方帮助文档与开发者文档(docs.obsidian.md / help.obsidian.md)
- 各开源项目的 GitHub 仓库与官方架构文档
- Local-first 领域的经典文献(Ink & Switch 论文)
- 社区深度技术分析文章(编辑器实现、同步协议、索引设计等)

每篇文档末尾附有主要参考资料链接。
